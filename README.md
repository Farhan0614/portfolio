- Dark / light theme with `next-themes`

## Local setup

\```
npm install
cp .env.local.example .env.local # then add RESEND_API_KEY
npm run dev
\```

## Notes

This is a public portfolio; secrets are NEVER committed. Email contact form requires `RESEND_API_KEY`.
